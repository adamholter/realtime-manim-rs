## Native translation lowering

The compatibility compiler now recognizes path snapshots whose every Bézier
coordinate differs only by one translation. It emits the path geometry once and
uses native Rust `x`/`y` tracks for motion. The check permits only `1.1e-6` world
units, matching the compiler's six-decimal coordinate rounding; morphs, scales,
rotations, gradients, and actual deformations remain full command tracks.

Same-source, same-`30 fps` payload comparisons:

| Scene | Before | After | Reduction | Lowered paths |
|---|---:|---:|---:|---:|
| `PrimitiveGallery` | 307,996 B | 174,642 B | 43.30% | 23 |
| `MatchingAndNumbersCompatibility` | 579,841 B | 306,398 B | 47.16% | 8 |

Six random browser seeks per scene compared the old command-track output against
the compact Rust-transform output at `854×480`. `PrimitiveGallery` was pixel exact
at all six times. The matching-text stress scene was exact at three times and
differed on only 9, 36, and 17 antialiased edge pixels at the other times, with
maximum normalized-frame RMSE `0.001555`; the compact trace retains every sampled
Manim frame while the old command trace used geometric simplification.

## Retained geometry and timeline sharing

Static Bézier geometry is now content-addressed inside each scene. Exact copies
become `pathRef` nodes; translation-equivalent outlines also share the concrete
path and retain only a local transform. This is especially effective for repeated
Text/Math glyphs and changing `DecimalNumber` digits. Eight sampled old/new frames
for both `TextAndMath` and `UpdatersAndTracedPath` were pixel exact.

Tracks can likewise use `keyframesFrom` for an identical timeline on the same
property. Rust validates that the source is concrete and unambiguous, then resolves
all concrete timelines through a per-evaluation hash map. Across the current corpus, 323
duplicate timelines were removed. A 20-scene, three-time browser differential was
pixel exact for every scene, with zero browser or WebGPU errors.

`TextAndMath` is now 264,651 B, down 72.5% from its 963,497 B expanded form.
`UpdatersAndTracedPath` is 187,765 B, down 56.4% from 431,127 B. The deterministic
compiler seeds Python, NumPy, and Manim configuration; two independent vector-field
compiles previously produced the same SHA-256 digest.

Multi-subpath `Write`, `Create`, `Uncreate`, `DrawBorderThenFill`, and

draw bounds. Redundant scalar keyframes are removed only when they are exactly

the same de Casteljau left-segment construction used by Manim. The compiler rejects
the lowering if any prefix or reconstructed partial control point differs by more
than `1.2e-6` world units.

`ParametricAndPolar` fell from 2,096,134 B to 183,640 B, a 91.24% reduction, by

The compiler's generic keyframe builder now retains the final frame of a constant
hold before a change. Previously, deduplication could interpolate early across a
long hold; the compact semantic traces preserve the sampled Manim timing instead.

## Native SVG alpha and luminance masks

SVG masks now remain vector paint. Rust tessellates each mask layer with the same
solid, multistop-linear, and focal-radial paint paths as visible content, renders
full premultiplied color into a lazily allocated 4x-MSAA GPU texture array, then
applies alpha or luminance coverage when the masked fragment is shaded. This order
preserves source-over semantics: an opaque black shape can punch a luminance hole
through an earlier white shape, while translucent gradients retain fractional edges.
Linked mask definitions compile to multiple layer descriptors whose coverage is
multiplied in the fragment shader. Mask regions and clip paths inside mask content
remain vector stencil geometry.

Masks nested inside mask content now use the same recursive model. Dependencies are
rendered first; every layer resolves into a separate scratch texture before being
copied into the sampled texture array, so WebGPU never reads and writes overlapping
texture subresources. The adversarial nested alpha/luminance fixture includes an
inner clip, multistop and focal gradients, black/white cutouts, and a masked stroke.
It rendered with zero browser or GPU errors and matched Chromium at mean absolute
channel error 0.55/255 and normalized RMSE 0.03168. The original mask fixture remained
pixel-identical to its prior native receipt after the compositor change.

The adversarial standard-SVG fixture combines an off-center alpha-gradient mask,
a multistop luminance mask, overlapping black/white cutouts, clipped regions,
gradient-painted content, and thick strokes. Its exact `854×480` WebGPU render has
full-frame mean absolute channel error 0.69/255 and normalized RMSE 0.01857 against
Chromium's native SVG renderer; the visible difference is edge coverage on a few
high-contrast pixels. The isolated run had zero JavaScript, page, shader, WebGPU,
or renderer errors. Mask textures do not exist in scenes that do not use masks.

## Native SVG vector patterns

SVG pattern fills and strokes now remain vector geometry. `usvg` resolves object-
bounding-box units, view boxes, inherited paint, and pattern transforms; Rust repeats
the normalized tile only across the visible document extent, clips every repetition
to its tile and owning fill or stroked outline with nested 4x-MSAA stencil levels,
and preserves solid, multistop-linear, and focal-radial child paint. Clip paths inside
tile children and alpha/luminance masks outside the patterned object compose normally.
No pattern tile is rasterized or handed to the browser renderer.

Pattern children may themselves carry linked alpha/luminance masks, including masks
nested inside mask content. Each transformed tile gets the correct vector mask-space
transform, while its descriptors multiply with any outer object mask. The dedicated
fixture matched Chromium at mean absolute channel error 0.92/255 and normalized RMSE
0.01509, with zero browser or WebGPU errors.

Pattern paints may also recurse. Nested pattern fills and strokes reuse the active
stencil stack, retain their own transforms, gradients, clips, and vector tiles, and
bound repetition to the painted path rather than the full document. The adversarial
two-level fixture matched Chromium at mean absolute channel error 1.41/255 and
normalized RMSE 0.02543, with zero runtime errors.

The adversarial fixture combines a rotated pattern, overflowing tile geometry that
must be clipped, a gradient child clipped inside every tile, solid and stroked child

## Native nested clip-definition semantics

Shapes carrying their own clip paths inside a clip definition are retained as a
recursive vector tree instead of being flattened into an incorrect union. Simple
clips stay on the fast stencil path; complex clip unions become lazily composed
4x-MSAA vector coverage layers, whose nested intersections are sampled by the parent
shape. Linked outer clip paths still intersect normally.

The adversarial three-level fixture combines an ordinary union member, a separately
clipped union member, a clip applied to that nested clip's path, a linked rounded
outer clip, gradients, a vector pattern, and a thick curve. It matched Chromium at
mean absolute channel error 0.12/255 and normalized RMSE 0.00622, with zero runtime
errors.
