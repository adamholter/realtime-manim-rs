# R-01 receipt — golden Manim parity corpus

Closed: 2026-07-30

This ticket defines the parity target. It does **not** claim that the Rust
runtime has reached it.

## Reference boundary

- Manim Community `0.20.1`
- 20 independently runnable scenes
- 13 capability tiers
- 111 named API/capability checks
- 52 behavioral and visual assertions
- reference size: `854×480`
- reference renderer: Manim Cairo
- reference command saves each scene's final frame

The corpus covers 2D primitives, text, markup, MathTex, graphing, animation
composition, updaters, cameras, SVG and images, layouts, networks, vector
fields, charts, boolean geometry, custom VMobjects, 3D surfaces and polyhedra,
audio, and international text.

## Capability boundary

`benchmarks/corpus/capability-matrix.json` records the current Rust status as
supported, partial, or missing. There are no permanent exclusions: the target
is full parity. A scene rendered by regular Manim cannot be counted as a Rust
pass, and an unsupported feature must produce a structured diagnostic rather
than a substitute visualization.

At close, no tier is marked fully supported. The runtime has useful partial
coverage in 2D, typography, graphing substrate, animation substrate, dynamic
bindings, 2D camera, SVG, geometry, and Unicode. Layout, data-viz APIs, 3D, and
audio remain missing.
