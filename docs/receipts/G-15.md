# G-15 decision — Manim compatibility tier

Updated: 2026-07-30

Decision: full Manim Community 0.20.1 capability parity.

Permanent exclusions: none.

The compatibility claim requires every capability in the 20-scene golden corpus to
pass structural, temporal, and visual assertions against regular Manim. A scene is
not counted as supported when the compatibility compiler reports a diagnostic,
falls back to an unrelated visualization, drops audio/media, or merely renders a
static final frame.

## Cost accepted

- retain the regular Manim Python frontend while native Rust APIs mature
- support compact compilation of arbitrary VMobject animation and updater state
- implement raster images, SVG paint servers/clips/masks, audio, subcaptions, 3D,
  PMobjects, and OpenGL-only behavior
- maintain deterministic native and Wasm rendering/export paths
- carry the 20-scene differential corpus as a release gate
- accept larger temporary compile artifacts until they are replaced with compact
  semantic operators; a 39.6 MB three-second surface compile is evidence of work
  remaining, not an acceptable steady-state result
