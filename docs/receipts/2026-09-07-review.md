# Correctness and workspace review

Base revision: `f886953`.

## Corrected mistakes

The September 1 QuickHull patch used `self.tolerance`, an absolute distance,
as NumPy's rank threshold. A full-rank tetrahedron with coordinates scaled by
`1e-6` raised `ValueError`, although upstream Manim accepted it. Rank now uses
NumPy's relative numerical threshold. The fixed local RNG and deterministic
fallback remain intact.

Ten geometry checks compare facet support, hull vertices, and area or volume
against SciPy's independent Qhull implementation. They cover 2D and 3D inputs,
scales from `1e-6` to `1e6`, duplicate/interior points, and the coplanar initial
simplex. Invalid rank-deficient inputs still fail explicitly. Three compiler
scenes repeat across four controlled entropy seeds. Existing tetrahedron and
pyramid hashes remain unchanged. The small-input scene now produces the same
17 nodes and exact JSON hash as upstream Manim with seed zero:

`0b06374de356da0d3565b432ada9e635360861b3a4d4b4f8e2b6b2f15911d7ee`

The heavy-scene benchmark previously divided frame counts by the requested wait
duration. It now samples frame counters with browser timestamps. In this run,
the polyhedra scene presented 61 frames over 1,030.6 ms, yielding 59.19 FPS.
The old formula would have reported 61 FPS. CPU totals now have separate measured
sample durations. Browser errors also make the JSON report's `acceptance.passed`
false. An injected console error verified both that field and exit code 1.
