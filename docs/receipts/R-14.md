# R-14 receipt — Manim authoring surface

Updated: 2026-08-10

Status: acceptance evidence complete

## Decision

The minimum authoring surface is regular Manim Community Python, not a replacement
JSON vocabulary. `GeneratedScene` runs with Manim's own `Scene.play`, Mobject,
animation, updater, camera, LaTeX, and rate-function semantics. The compatibility
compiler samples the resulting cubic vector state at explicit frame times and emits
validated Rust scene IR. The compact scene IR remains the runtime and interactive
control format.

Generated Python runs under `sandbox-exec` with network denied, writes restricted to
one temporary directory, and reads denied under the user's home and mounted volumes
except the isolated Manim environment, compiler, and fonts. A deliberate read of the
repository failed with `Operation not permitted`; ordinary geometry and MathTex
compiled successfully.

## Three authoring/edit trials

Token counts use `tiktoken` `o200k_base` as a repeatable estimate, not a claim about
OpenRouter's private accounting.

| Scene | Python lines | Tokens | Compile wall time | Rust vectors | Rust tracks | Compiled bytes |
|---|---:|---:|---:|---:|---:|---:|
| `TransformFamily` | 10 | 145 | 715 ms | 3 | 6 | 122,301 |
| `UpdatersAndTracedPath` | 11 | 169 | 743 ms | 153 | 71 | 1,093,557 |
| `ThreeDSurface` | 15 | 162 | 10,729 ms | 669 | 2,983 | 39,579,242 |

The trials cover chained transforms and replacement, `ValueTracker` plus arbitrary
updaters and `TracedPath`, and `ThreeDScene` with a shaded checkerboard surface and
ambient camera rotation. All three compiled without compatibility diagnostics.

The 3D payload is correct but unacceptable as the final representation. Geometry and
paint snapshots must be deduplicated or replaced with native parametric/animation
operators before this path is considered performance-complete.

P-18 now lowers provably pure path translations to native Rust `x`/`y` tracks.
At equal `30 fps`, this reduced `PrimitiveGallery` by 43.30% and the matching-text
stress scene by 47.16%; see `docs/receipts/P-18.md`. Affine scale/rotation and the
large 3D surface payload remain open.

## Diagnostic quality

- `SvgAndImage`, `AudioTimeline`, Cairo/OpenGL point clouds, smooth OpenGL
  surfaces, and perspective-textured OpenGL images now compile without diagnostics.
- custom ShaderWrapper programs execute through translated WebGPU pipelines;
  topology, material, texture, point-count, and program-layout changes split
  into exact retained lifetimes.
- generated code receives one automatic Terra repair attempt with the exact bounded
  compiler/compatibility error.
- a compatibility result is not labeled supported when the compiler reports a gap.

## Live end-to-end proof

Request: circle-to-square morph with MathTex and indication.

- model: `openai/gpt-5.6-terra` via `@openrouter/agent`
- streamed source: real `from manim import *` / `GeneratedScene`
- agent: 3.28 s
- sandbox compile: 5.70 s
- deterministic Rust/WebGPU render: 1.41 s
- total: 10.38 s
- output: 3.3 s, 30 fps, 99 exact frames, 83 KB WebM
- browser: 82 fps after render; no page or console errors
