## Honest boundary

This closes the scene-model/evaluator prototype, not Manim parity. The evaluator
still allocates transient property state and an output-node vector each frame.
Renderer-side tessellation caching and dirty GPU-buffer uploads remain performance
work. Python updater semantics, transform correspondence, and 3D are separate parity
frontiers.
