# P-12 progress receipt — interactive WebGPU/Wasm host

Updated: 2026-08-10

Status: usable local prototype delivered; the full P-12 evidence gate remains open
until Safari and HTTPS tracing plus repeatable performance capture are complete.

## Delivered

- Rust `1.88.0` → Wasm browser application using `wgpu 30.0.0`
- local Node server using `@openrouter/agent 0.8.0`
- GPT-5.6 Terra model contract: `openai/gpt-5.6-terra`
- in-memory OpenRouter key sessions with HttpOnly localhost cookies and eight-hour expiry
- validated `scene({...});` retained IR as the direct runtime format
- streamed regular Manim Python, sandbox execution, compatibility compilation, and
  double-validated Rust IR
- one automatic Terra repair attempt when generated Manim code fails compilation or
  compatibility validation
- 64-entry content-addressed in-memory Manim compile cache keyed by normalized code,
  FPS, compiler revision, asset names, and asset bytes
- general batched lyon/WebGPU vector renderer
- Rust-owned retained scene evaluation and keyframe interpolation
- Rust-owned animation clock, pause/resume, reset, resize, device-pixel scaling,
  uniform uploads, command encoding, submission, and presentation
- automatic WebGPU device-loss recovery with scene, signals, pause/seek state, and
  render-size restoration
- live Rust signal sliders declared by generated scenes
- always-available explicit-time scrubber with resume from the selected time
- automatic semantic slider for a user-authored monotonic Manim `ValueTracker`
- exact-frame WebCodecs/WebM export plus labeled MediaRecorder fallback
- playback, download, and agent/render/total timing
- explicit WebGPU failure state
- release build and localhost scripts
- persistent macOS LaunchAgent with automatic restart
- responsive desktop and mobile layouts
- no Wasm threads, worker, `SharedArrayBuffer`, COOP, or COEP requirement

This is a renderer option proof. It does not freeze the final renderer before `D-20`.
