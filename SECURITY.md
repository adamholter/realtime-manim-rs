# Security

Please report vulnerabilities through GitHub private vulnerability reporting for
this repository. Do not include credentials, private user assets, or working exploit
details in a public issue.

The local animation studio accepts an OpenRouter key at runtime. Reports involving
that flow should use a revoked test key and should describe whether exposure is in
the browser, local server, generated scene sandbox, logs, or package output.

This project is experimental and has not received an independent security audit.
